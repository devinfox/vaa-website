Voice Alchemy Academy

Email Nurture System for Every Funnel

Strategy handoff for building CRM email templates and automated funnels. Email template previews use the CRM builder's 600px canvas width. The campaign strategy assumes the website is student-first, teachers enter through demo capture, and mentorship applicants land on a higher-touch founder-led application path.

Executive Funnel Map

Primary Funnel

Student Free App Signup

Goal: get singers into the app fast, activate tool usage, create a practice habit, then monetize through AI, courses, storage, and mentorship.

  • Landing: /signup?role=student&src=landing
  • First action: open Training Center
  • Core promise: "Stop guessing. See yourself improve."
Teacher Funnel

Platform Demo Request

Goal: qualify coaches and studios into a walkthrough where the product is sold through their real teaching workflow.

  • Landing: #teacher-demo or future /demo
  • First action: request demo
  • Core promise: "See what students practiced before every lesson."
Premium Student Funnel

1:1 Mentorship Application

Goal: turn high-intent students into completed voice applications and booked admissions conversations.

  • Landing: /mentorship
  • First action: start Voice Application
  • Core promise: founder-led, app-enhanced vocal transformation
Fallback Funnel

Cold Lead / Exit Intent

Goal: capture visitors who are not ready to create an account, apply, or request a demo.

  • Landing: relevant original page
  • First action: email capture
  • Core promise: useful resource, not a newsletter

Do not lead with trial limits. Lead with what they have already felt: the relief of seeing their voice. Upgrade emails should make the next layer feel natural, not punitive.

What Should Happen Next

  1. Create the two resources: student "3 Pitch Mistakes" and teacher "Between-Lesson Practice Visibility Playbook." Keep both short and polished.
  2. Add hidden tracking fields to website lead/demo/app forms: persona, source, intent, landing page, CTA id, utm_source, utm_campaign, utm_content.
  3. In the CRM, create tags: student_free_signup, student_lead_magnet, student_active, student_inactive, teacher_demo_requested, teacher_demo_booked, teacher_post_demo, mentorship_started, mentorship_submitted.
  4. Build templates from the list above using the 600px email canvas and VAA header/footer styling.
  5. Build automations only after tags exist. Start with Student Activation, Teacher Demo Request, and Mentorship Application Received.
  6. Add conversion events: email open, click, account created, first tool used, demo requested, demo booked, mentorship application submitted.
  7. Review performance weekly. Optimize the first email and CTA before adding more complexity.

Strategic priority: do not make every funnel sell everything. Students need momentum. Teachers need a conversation. Mentorship candidates need trust and specificity.
